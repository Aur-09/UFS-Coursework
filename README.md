# UFS Coursework

This repository keeps University of the Free State (UFS) coursework in one place, grouped first by subject area, then academic year and course. Programming coursework belongs under `Programming/`; standalone products remain in their own project repositories.

## Structure

```text
Programming/
└── 2026/
    ├── CSIS1614/
    │   └── Practicals/
    ├── CSIS1624/
    │   └── Semester-Test-2/
    └── CSIS1664/
        └── Tutorial10/
            └── LevelUp/
```

The CSIS1624 semester test and CSIS1664 Tutorial 10 materials were imported from the `Aur-09/Programming` and `Aur-09/Web-Development` repositories, respectively. Their source files and required assets are preserved; generated CSIS1624 build output is excluded. CSIS1614 practicals are not included yet; that folder is ready for the files to be uploaded.

## Adding coursework

Keep new work under its subject area and year, then group it by course and assignment, tutorial, practical, or test. Preserve the original project files and assets, and leave generated build output, caches, and secrets out of the repository. Do not create placeholder coursework for files that have not been supplied.
